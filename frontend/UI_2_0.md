# AMAN Gate 2.0 UI (WP4) — contract, real-vs-mock map, re-pointing guide

Frontend only. No `backend/` file is touched. The Privacy Shield / Safe Cloud Bridge / Output Assurance
endpoints do **not exist yet**; the UI is built against the provisional contract below and falls back to
**labelled** sample data when a route returns 404/405.

## Provisional contract (single source: `src/api.ts`)

| Call | Request | Response (typed in `api.ts`) |
|---|---|---|
| `POST /api/privacy/analyze` | `{document_id}` | `{disclosure:{elements:[{id,type,page,sensitivity,source_trust,action}],findings_count}, safe_artifact_id, decision, blocked_reason?}` |
| `GET /api/privacy/artifacts/{id}` | — | `{original_preview, safe_copy_preview, findings:[{type, start?, end?, original?, replacement?, action?, sensitivity?, page?}]}` |
| `POST /api/bridge/send` | `{artifact_id, provider_mode}` (`LOCAL_SIMULATOR`\|`LOCAL_LLM`\|`REAL_CLOUD`) | `{mode:"LOCAL_SIMULATOR", response, watermark:true, egress_blocked_reasons?}` |
| `POST /api/assurance/check` | `{response}` | `{placeholder_integrity, leaks:[], flags:[], rehydrated}` |

Shapes the contract leaves open are read defensively through `src/lib/contract.ts`:
`decision` → `normalizeDecision` (unknown values fail safe to *Ready for review*); `findings` are highlighted by
`start/end` offsets, else by the literal `original`/`replacement` strings; `placeholder_integrity` may be a
boolean, string or object; `leaks`/`flags` may be strings or objects; `rehydrated` may be a string or `null`/`false`.
`blocked_reason` is an optional extra, not part of the agreed contract.

### Re-pointing
1. Paths: `ENDPOINTS` in `src/api.ts`.  2. Shapes: the interfaces just above the transport section.
3. Remove sample data: set `USE_MOCK = false` (build-time) or pick **Live only** in Settings; delete `src/mock.ts` and
   the `fallback` arguments in `privacy` / `bridge` / `assurance` when the backend is real.

A fallback is used **only** for a router-level 404/405 (`"Not Found"` / `"Method Not Allowed"`); a real handler's
structured error (`{code,message}`) is shown as an error, never mocked. Modes (Settings, per browser session):
*Auto* (default) · *Always simulate* · *Live only*.

## What is real vs mock

| Panel | Source |
|---|---|
| Login, Document registry + ACL (`/api/documents`, `/api/documents/{id}`) | **Real** |
| Overview KPIs **Blocked / Pending / Audit** (`/api/metrics`) | **Real** (tagged LIVE) |
| Overview KPI **Protected** | Session counter of safe copies made in this tab; tagged MOCK when any came from the fallback, `—` until one exists |
| Hero before any analysis | Built-in synthetic sample, labelled *Sample preview — not your document* + MOCK |
| Detection, findings, safe copy, decision | Backend if `/api/privacy/*` exists, else **MOCK**: a browser-side regex detector over the **real** document text returned by the gateway; a real ACL denial still yields BLOCKED |
| Safe-copy verification list | UI cross-check of the returned preview (not the backend's second-extractor verification) |
| Approve Sharing | **UI session only** — not written to the 1.0 approval queue or audit chain |
| Safe Cloud Bridge response | Backend if available, else **MOCK** canned text; always the local simulator, never a real AI |
| Output Assurance checks | Backend if available, else **MOCK** deterministic checks against the most recent artifact |
| AI Agent Firewall (live demo, replay, policies, approvals), Evidence & Research, Document registry | **Real** AMAN 1.0 endpoints, unchanged |

A persistent **Simulation** watermark + header chip is shown on Overview, Protect Documents (Privacy Shield), Safe Cloud
Bridge, Output Assurance and Judge Demo, and the bridge response carries its own watermark. Real-data tabs show none.

## Design system
Light theme (`#F7F9FC` page, white cards, `#0F233F` ink, single teal `#087F8C`, amber `#D97706`, red `#C0363D`),
Inter (variable, OFL) vendored in `src/fonts/` — no CDN. Tailwind token names from 1.0 (`navy-*`, `slate-*`,
`allow`, `approve`, `deny`) were kept and re-pointed to light values so the 1.0 tabs re-theme without logic changes;
`*-ink` variants are the AA-safe accent text colours. State is never colour-only (icon + word + legend numbers).
